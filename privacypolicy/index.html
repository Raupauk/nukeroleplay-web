2. General Information

We take the protection of your personal data seriously. Personal data is processed only where this is necessary for the operation, security and functionality of the NukeRoleplay website and Minecraft server, or where another applicable legal basis permits such processing.

This Privacy Policy explains what personal data may be processed, why it is processed, how it is used and what rights you have under applicable data protection law, including the General Data Protection Regulation (GDPR).

3. Data Processing When Visiting This Website

The website does not use user accounts, cookies, analytics systems, advertising trackers or contact forms.

No personal data is intentionally collected through a registration or contact form on this website.

However, when you access a website, technical connection data may be processed by the hosting provider. Depending on the hosting provider's configuration, this may include information such as your IP address, timestamp, requested resource, browser type and operating system.

Such processing may be necessary to deliver the website securely and reliably and to protect the infrastructure against abuse, attacks and technical errors.

4. Minecraft Server Status

This website uses the public mcsrvstat.us service to display the current status of the NukeRoleplay Minecraft server.

For this purpose, the website sends a request to the mcsrvstat.us service. The request is used to retrieve technical server information, such as whether the Minecraft server is online and the current player count.

The website does not intentionally send your Minecraft username, UUID or other player information to mcsrvstat.us as part of this status request.

The processing of connection data by the external service may be subject to that service's own privacy practices.

5. Discord API

This website uses the Discord API to display the number of currently online members of the NukeRoleplay Discord server.

For this purpose, the website makes a request to Discord's API using the public server information required for the widget.

The website does not require you to log in to Discord and does not use the Discord API to create a user account on this website.

Discord may process technical connection information when its API is accessed. Such processing is governed by Discord's own privacy practices and policies.

6. Data Processing on the Minecraft Server

When you connect to and use the NukeRoleplay Minecraft server, certain data is processed for the operation and administration of the server.

This may include:

  • Minecraft username
  • Minecraft UUID
  • Server-related gameplay information required for the operation of the server

Minecraft usernames and UUIDs are used to identify player accounts and to provide server features such as player data, permissions, gameplay progression and other server functionality.

The processing is generally based on Article 6(1)(f) GDPR, where necessary for the legitimate interests of operating, securing and administering the Minecraft server.

7. Voting and IP Addresses

NukeRoleplay may receive an IP address when a player votes for the server on an external Minecraft server voting service.

The IP address may be used to process and validate voting activity, prevent abuse, detect fraudulent voting attempts and ensure that voting rewards are granted correctly.

IP addresses are processed only for purposes connected with the voting system, server security and abuse prevention.

Where an IP address is received from an external voting service, the applicable external service may also process the IP address under its own privacy policy.

8. Discord Verification

NukeRoleplay provides a verification system that can connect a Minecraft player account with a Discord account.

As part of this process, the Discord user ID may be stored together with the relevant Minecraft account information.

The Discord user ID is used to verify the connection between the Discord account and the Minecraft account and to provide verification-related server functionality.

The processing is generally based on Article 6(1)(f) GDPR, insofar as it is necessary for the legitimate interests of operating the verification system, securing the server and preventing abuse.

9. Storage Period

Personal data is stored only for as long as necessary for the respective purpose for which it was collected or as required by applicable law.

Minecraft usernames and UUIDs may be retained for as long as necessary to maintain player accounts and the associated server functionality.

Discord user IDs associated with the verification system may be retained for as long as the verification relationship is required for the server's functionality.

Voting-related IP addresses are retained only for as long as necessary for voting validation, abuse prevention and related server-security purposes.

Technical hosting logs are retained according to the applicable configuration and retention policy of the hosting provider.

Data is deleted or anonymised when it is no longer required for the relevant purpose and no legal obligation requires continued retention.

10. Recipients and External Services

Personal data may be processed by technical service providers where this is necessary for the operation of the website or server.

Depending on the service involved, these may include:

  • The website hosting provider
  • The Minecraft server hosting provider
  • Discord, where Discord-related services or the verification system are used
  • External Minecraft voting services, where voting activity is processed
  • mcsrvstat.us for the server-status request described above

External providers may process data in accordance with their own privacy policies and, where applicable, as processors acting on behalf of the controller.

11. International Data Transfers

Some external services used by the website or Minecraft server may process data outside the European Economic Area (EEA).

Where personal data is transferred to a country outside the EEA, the transfer must comply with the applicable requirements of Chapter V GDPR, including where applicable an adequacy decision or appropriate safeguards.

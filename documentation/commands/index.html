Commands

A guide to the most important commands available to players on NukeRoleplay.

Commands / Overview

Your command
guide.

NukeRoleplay offers a variety of commands that allow you to communicate with other players, manage your vehicles, access properties and interact with different systems around the server.

The commands below are some of the most important commands you should know when playing on the server.

Tip: Keep this page bookmarked so you can quickly look up a command whenever you need it.

Category / Communication

Communication

COMMAND · 01
/team chat

Team Chat

Chat with the other members of your team. Everyone on your team will be able to see your message.

COMMAND · 02
/team allychat

Team Ally Chat

Communicate with all allied teams. This is especially useful for players on the police team who need to communicate with other police teams.

COMMAND · 03
/msg <Playername> <Message>

Private Message

Send a private message to another player. The other player can reply by using the same command.

COMMAND · 04
/help <Message>

Moderator Help

Send a help request to all online moderators when you need assistance as soon as possible.

Important · /help

Do not abuse the help command. Misusing it may result in a punishment.

Category / Missions

Missions

COMMAND · 05
/missions

Mission Menu

Open the missions menu to see missions you have completed, missions currently in progress and missions you have not discovered yet.

Category / Vehicles

Vehicles

COMMAND · 06
/delcar

Despawn Vehicle

Despawn your currently spawned vehicle.

COMMAND · 07
/lockcar

Lock Vehicle

Lock your vehicle to prevent unauthorized access.

COMMAND · 08
/unlockcar

Unlock Vehicle

Unlock your vehicle so it can be accessed again.

Category / Housing

Housing

The housing commands make it easier to access your properties and manage the permissions of other players.

COMMAND · 09
/tphome

Teleport Home

If you own a property, use this command to teleport to your home whenever you want.

COMMAND · 10
/house <Housename> trust <Playername>

Trust a Player

Give another player permissions for one of your properties.

COMMAND · 11
/house menu

House Menu

Open the house management menu where you can manage the permissions you have given to other players.

Security · Housing Permissions

Only trust players you know and trust. Giving another player access to your property can give them permissions inside your house.

Category / Privacy

Privacy

COMMAND · 12
/bmpc

Map Marker

Toggle whether your player marker appears on the live map on the NukeRoleplay website.

This can be useful when you do not want your current position to be visible on the live map.
